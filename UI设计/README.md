## 1. 设计目标

覆盖创面评估 V1 主流程的 **10 个核心页面**：工作台 → 患者列表 → 患者详情 → 拍照 + AI 测量 → 临床量表评估 → 电子签名锁定 → **数据汇总 → 研究中心 → 试验方案 → 方案详情**。所有页面在 `390×844`（iPhone 14）画板上完成 1:1 设计，可直接交付 Flutter 移动端开发。

### 2.1 工作台（01）
- **状态栏** + **头部**："早上好，李医生" 问候 + 日期 + 通知铃铛 + 头像
- **今日概览**（灰底胶囊三宫格）：待评估 3 / 待签名 2 / 今日随访 5
- **主操作**：「+ 新建创面评估」Action Blue 大圆角按钮
- **最近评估**（无阴影白卡）：
  - 王秀兰·女 72 岁 · 压力性损伤 2 期 · 面积 3.2 cm² · 状态「待签名」（黄）
  - 张建国·男 68 岁 · 静脉溃疡 · 面积 8.5 cm² · 状态「已锁定」（绿）
- **底部胶囊 Tab Bar**：首页（激活）/ 患者 / 评估 / 我的

### 2.2 患者列表（02）
- 标题「患者管理」+ 右上角「扫一扫」（腕带扫码入口，取景框 + 蓝扫描线图标）与「+」添加按钮
- 搜索框："搜索姓名 / 病案号"
- 筛选 chips：全部（蓝）/ 住院 / 门诊 / 随访中
- 列表数量：「患者 · 4」
- 3 张患者卡：王秀兰（住院）/ 张建国（住院）/ 刘桂芳·女 75 岁（门诊）
- 每张卡：姓名 + 性别 + 年龄 + 类型 chip + 病案号 + 创面描述
- 底部 Tab Bar，激活态切换到「患者管理」

### 2.3 患者详情（03）
- 顶部：返回 + 标题 + 「...」操作菜单
- 患者信息卡（白卡）：王秀兰·女 72 岁 + 「住院」chip + 病案号 / 创伤骨科 3 床 / 入院诊断 / 入院日期
- **当前创面卡**（重点）：缩略图 + 部位 + 分期 + 肉芽 65% + **面积 3.2 cm²** + AI 测量时间戳
- **评估历史**列表：08-28 VSS7·NRS4·3.2 cm²「待签名」/ 08-21 VSS9·NRS5·4.8 cm²「已锁定」/ 08-14 VSS11·NRS6·6.1 cm²「已锁定」
- **数据汇总入口卡**（白卡）：折线图标 + 「数据汇总 / 面积·VSS 趋势」+ 右箭头，点击进入 07 页
- 底部「新建创面评估」主按钮

### 2.4 拍照 + AI 测量（04）
- 步骤指示器：1/4
- **取景区**（深色占位）：显示「AI 已识别·分割完成」角标，红色创面轮廓 + 1 cm 比例尺
- **测量结果三宫格**：面积 3.2 cm² / 最长径 2.4 cm / 宽度 1.8 cm
- **组织构成（AI 分析）**：水平条形图 + 图例
  - 🟢 肉芽 65% / 🟡 腐肉 25% / 🔴 坏死 10%
- 拍摄建议（浅灰小字）："光线充足 · 垂直拍摄 · 距离 15–20 cm"
- 底部：「重新拍摄」次按钮 + 「确认测量」主按钮

### 2.5 临床量表评估（05）
- 步骤指示器：2/4
- 标题「临床量表评估」+ 副标题"VSS 温哥华瘢痕量表 · NRS 疼痛评分 · 创面分期"
- **VSS 温哥华瘢痕量表**（总 7 分）：
  - 血管分布 0–3 分（选中 0）
  - 厚度 0–3 分（选中 1）
  - 柔软度 0–5 分（选中 3）
  - 色素沉着 0–3 分（选中 2）
- **NRS 疼痛评分**（4 分）：0 无痛 → 10 剧痛，蓝色滑块 + 灰色刻度
- **创面分期**：1期 / 2期（选中）/ 3期 / 4期 / 不可分期
- 底部：「上一步」+「下一步」

### 2.6 签名锁定（06）
- 步骤指示器：4/4（终点）
- **评估汇总编辑**卡：患者 / 创面 / 评分 / 时间 四行
- **合规声明**（蓝底白字小卡）：🔒 电子签名确认后，本次评估记录将被锁定，任何内容不可修改。所有操作自动留痕，纳入审计追踪（符合 GCP / 21 CFR Part 11）
- **手写签名区**："请在此签名"（虚线占位）
- 签名人：姓名（李慧·副主任医师）+ 工号 LI-0284 + 签署时间（服务器自动）
- 底部：「🔒 确认签名并锁定」主按钮 + 「保存草稿」次按钮

### 2.7 数据汇总（07）
- 顶部：返回 + 标题「数据汇总」+ 右上角患者名
- 患者摘要行："王秀兰 · 女 72岁 · 左足跟压力性损伤 · 已评估 3 次"
- **指标切换 Tabs**（灰底胶囊分段）：创面面积（选中蓝）/ VSS 总分
- **创面面积变化卡**：标题 + 单位 cm² + 绿色降幅 chip「较 08-14 ↓48%」
  - 折线图 3 个数据点：6.1 → 4.8 → 3.2 cm²（08-14 / 08-21 / 08-28）
  - 尾注："数据来源：历次已锁定评估记录"
- **统计摘要三宫格**：首次 6.1 cm² / 最新 3.2 cm² / 总降幅 2.9 cm²（绿色数值）
- **VSS 总分变化卡**：chip「瘢痕改善」，折线 11 → 9 → 7（与 03 页评估历史数据一致）
- 底部提示："曲线随每次锁定评估自动更新"

### 2.8 研究中心（08）

### 3.3 字体

| 用途 | 字体 | 字号 |
|------|------|------|
| 中文 | **Noto Sans SC** | 大标题 28 / 标题 20 / 正文 15 / 辅助 13 / 极小 11 |
| 数字 / 时间 | **Inter** | 评估大数字 24 / 数据 17 / 时间戳 12 |

> 字体替代策略：Noto Sans SC（无衬线）作为 PingFang SC 替代，Inter 与 SF Pro 数字字形一致。避免依赖客户端预装字体时回退掉档。

### 3.4 组件
- **胶囊 Tab Bar**：高度 62 / 圆角 36 / 白底 1px 描边，激活态使用 Action Blue 实心圆 + 白图标
- **白卡**：圆角 18 / 1 px 浅灰描边 / 无阴影
- **数据三宫格**：均分父容器宽度，垂直居中
- **量表 chip**：圆角 8 / 高 32 / 选中态 Action Blue 填充 + 白字；未选中灰边
- **NRS 滑杆**：水平 318×44 容器 + SVG 进度条 + 圆形 thumb（直径 20）
- **状态 chip**（待签名/已锁定）：圆角 6 / 浅色底 + 深色字

### 3.5 栅格与间距
- 左右页边距 20 / 卡片间距 12 / 卡片内边距 16
- 文字行高 1.4–1.5，量表行高 1.6

## 4. 合规元素落点（21 CFR Part 11 / GCP / PIPL）

| 合规要求 | 实现位置 |
|---------|---------|
| 评估记录不可改 | 签名页 06「锁定」主按钮 + 锁定后状态色标 |
| 操作自动留痕 / 审计追踪 | 签名页合规声明文案明确"所有操作自动留痕" |
| 电子签名（防抵赖） | 06 页手写签名板 + 签名人姓名 / 工号 / 服务器时间戳 |
| 数据访问控制 | 列表/详情页只显示当前操作者有权访问的患者 |
| 数据脱敏（病案号/姓名） | V1 阶段暂不脱敏，规格书已要求预留接口 |

## 5. 与现有资料的一致性

- **数据样例**：演示数据使用 cm²（已与 8-28 单位修订说明一致：`创面评估系统_V1_单位修订说明_cm版.md`）
