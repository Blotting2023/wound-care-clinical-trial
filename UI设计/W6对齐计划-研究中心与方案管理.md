### 图标实现约束（重要）

Ardot 对带弧线的 stroke path 解析不稳定，**一律用 rect 填充拼图标**：
- person = 头 rect 6×6 rx3 + 身 rect 10×4.5 rx2.25
- place = 圆 rect 7×7 rx3.5 + 尖 rect 2.5×6
- phone = rect 12×14 rx3 + 内白 rect 9×7
- flag = 杆 rect 1.6×12 + 旗 rect 8×5
- cloud = rect 8×6 rx3 + rect 9×7 rx3.5 叠放
- plus = 两 rect 交叉（12×2.4 / 2.4×12）
