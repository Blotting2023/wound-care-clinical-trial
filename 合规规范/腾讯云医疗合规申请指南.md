# 腾讯云医疗合规申请指南（创面评估 App V1）

> 目标：开通「腾讯云 COS + KMS 医疗数据合规白名单」，让创面照片 + CRF 数据合法存储
> 申请路径：2026 年 9 月最新版
> 适用对象：老胡 / 院方 IT / GCP 办公室

---

## 一、为什么需要单独申请？

腾讯云普通 COS Bucket 可以存任何文件，但**医疗数据（含可识别个人身份的影像 + 病历）**需要：

1. **地域合规**：必须落到医疗合规节点（广州 `ap-guangzhou` / 上海 `ap-shanghai`），普通地域审核会卡
2. **加密合规**：必须开 SSE-KMS + 自带主密钥（CMK），不能用 SSE-COS（默认加密）
3. **白名单准入**：医疗数据敏感字段（身份证 / 病历号 / 影像 / 检验报告）必须事先申请白名单，未申请直接上传会被审计拦截
4. **密钥隔离**：KMS 实例需企业实名 + 医疗资质；个人开发者账号无法开医疗合规 KMS

| 材料 | 说明 |
|------|------|

### 技术信息（必交）

| 材料 | 说明 |
|------|------|
| 数据流图 | 标注数据从 App → 后端 → COS / KMS 的完整路径 |
| 数据分类清单 | 列明哪些字段属于「医疗数据 / 个人敏感信息」 |
| 加密方案 | 描述 SSE-KMS + 自带主密钥（CMK）的实现 |
| 访问控制方案 | 描述 RBAC 矩阵 + 审计日志 + 数据留存期 |
| App 包名 / Bundle ID | iOS：`com.woundassessment.woundAssessment`；Android 待定 |

### 安全承诺（必交）

- 数据不出境承诺（境内存储 + 境内 API）
- 数据留存期承诺（10 年以上）
- 数据销毁 SOP（到期 + 审批 + 销毁记录归档 ≥5 年）

## 六、申请通过后的配置要点（W4.2 用得上）

### COS Bucket 创建

```
地域：ap-guangzhou 或 ap-shanghai（医疗合规节点）
名称：wound-photos-prod-{机构代码}
存储类型：标准存储
加密：SSE-KMS（选自带 CMK）
版本控制：开启
日志：投递到 CLS（日志服务）
跨区复制：备份到 ap-beijing-2
生命周期规则：
  - 原始照片：10 年后转归档存储 → 再 5 年后彻底删除
  - 临时文件：30 天后删除
  - 缩略图：5 年后删除（不参与原始数据留存）
```

### KMS 实例

```
实例名称：wound-assessment-kms
地域：与 COS 同地域
密钥策略：仅授权服务端 ECS / SCF 可解密
密钥轮换：每年自动轮换一次
密钥审计：开启 CloudAudit 全量记录
```

### RAM 子账号 + 策略

```json
{
  "version": "2.0",
  "statement": [
    {
      "effect": "allow",
      "action": [
        "cos:PutObject",
        "cos:GetObject",
        "cos:InitiateMultipartUpload"
      ],
      "resource": [
        "qcs::cos:ap-guangzhou:uid/1250000000:wound-photos-prod-*/original/*"
      ]
    },
    {
      "effect": "deny",
      "action": [
        "cos:DeleteObject",
        "cos:DeleteBucket"
      ],
      "resource": "*"
    }
  ]
}
```

### IAM 权限：禁止任意删除（强制）

```
- 任何人 / 角色都不能直接 DeleteObject
- 删除必须走服务端审批接口（PI / Admin 二次确认 + 写 AuditLog）
- 销毁 SOP 文档记录每次审批 → 销毁批次号 + 操作人 + 时间
```

## 七、未通过的备选方案

如果腾讯云医疗合规申请未通过（或时间来不及），按以下优先级降级：

| 备选 | 优势 | 劣势 |
|------|------|------|
| **阿里云医疗云** | 已获医疗数据合规认证；申请流程成熟（7-10 天） | 切换工作量大；SDK 改写 |
| **院内 MinIO 私有化** | 完全可控；数据不出院 | 需要 IT 部门投入运维；缺医疗合规背书 |
| **华为云医疗合规** | 已认证；面向医院有专门方案 | 生态弱；移动端 SDK 不如腾讯云稳定 |
