### 任务 W1.3 审计日志 ORM 拦截层（5 天）

**改动文件**
- `lib/services/audit_logger.dart` 🆕 — `record(table, recordId, opType, fieldName, before, after, reason)` API
- `lib/services/demo_backend.dart` — 所有 `_assess() / _updateXxx()` 方法改成走 `_withAudit()` 包装器
- `lib/services/audit_chain.dart` 🆕 — `prevHash + hash` 链式校验（hash = sha256(table + recordId + field + before + after + operatorId + occurredAt + prevHash)）

**数据库层（生产）**
```sql
CREATE TABLE audit_log (
  id BIGSERIAL PRIMARY KEY,
  table_name VARCHAR(64) NOT NULL,
  record_id VARCHAR(64) NOT NULL,
  op_type VARCHAR(16) NOT NULL CHECK (op_type IN ('CREATE','UPDATE','DELETE','SIGN','LOCK','UNLOCK','ACCESS_DENIED','EXPORT')),
  field_name VARCHAR(64),
  before_value JSONB,
  after_value JSONB,
  reason TEXT,
  operator_id VARCHAR(64) NOT NULL,
  operator_name VARCHAR(128),
  operator_ip INET,
  device_fingerprint VARCHAR(128),
  app_version VARCHAR(32),
  occurred_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  prev_hash CHAR(64),
  hash CHAR(64) NOT NULL,
  INDEX idx_audit_record (table_name, record_id, occurred_at)
);
REVOKE UPDATE, DELETE ON audit_log FROM app_user;
GRANT INSERT, SELECT ON audit_log TO app_user;
```

**验收**
- [ ] 在 UI 改一处患者姓名 → 数据库同时新增 1 条 AuditLog `opType=UPDATE fieldName=name`
- [ ] 改"理由"为空 → 后端拒收，返回 400
- [ ] 直接 `UPDATE audit_log SET reason='x'` → 报 42501 permission denied
- [ ] 校验链：任意一条记录 hash 篡改 → 后续链全部校验失败
